## 🚀 Project Overview
AI-based system jo system logs se cyber threats detect karta hai, risk score deta hai aur real-time alerts bhejta hai.

## 🎯 Features
- ✅ Live Threat Detection (IP, Port, Failed Logins)
- ✅ Risk Score 0-100%
- ✅ SAFE / SUSPICIOUS / CRITICAL Alerts
- ✅ Live Attack Simulation (Demo ke liye)
- ✅ Detection Log
