### 🎯 Problem Statement
80% students use AI tools like ChatGPT. Traditional plagiarism checkers fail to detect AI-generated content. No photo-to-text search exists.

### ✅ Our Solution - 6 in 1 Platform
Cyber Shield detects AI vs Human content in real-time with 6 super powers:

1.  **Single Check:** Paste text → Get AI % + Plagiarism Score in 2 sec
2.  **Bulk Check:** Check 100 URLs/Files at once + Export Excel
3.  **📸 Photo Search:** Click photo → Tesseract.js OCR → Find source (Unique!)
4.  **Humanizer:** Convert AI text to Human-like to bypass detectors
5.  **🎤 Voice Search:** Bolke search karo - Hands-free
6.  **History & Reports:** Auto-saved with PDF/CSV export

### 💻 Tech Stack
- **Frontend:** HTML5, Tailwind CSS, Vanilla JS (100% Single File)
- **AI Engine:** Custom NLP + Perplexity Score + Burstiness Analysis
- **OCR:** Tesseract.js (Client-side, 100% Private)
- **Deployment:** GitHub Pages
