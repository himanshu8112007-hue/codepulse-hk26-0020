### About Project
Cyber Shield is a frontend-only AI content detector that detects whether text is written by AI or Human. It uses perplexity, burstiness, and trigger-word analysis.

### Features (All Working - No Backend)
- ✅ Single Check - Paste text and get AI score, plagiarism %, human score
- ✅ Bulk Check - Upload 10 files at once, classroom mode, CSV export
- ✅ OCR Scan - Photo se Search using Tesseract.js (Hindi + English)
- ✅ URL Scan - Paste any blog URL
- ✅ AI Humanizer (Paraphraser) - Convert AI text to human
- ✅ Voice Search - Bol ke search karo (Web Speech API)
- ✅ Sentence Highlighting - Red = AI, Green = Human
- ✅ Blockchain Certificate - Hash based verification
- ✅ Multi-language - Hindi, English, Hinglish

### Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Tailwind CSS
- Tesseract.js for OCR
- Web Speech API

### How to Run in VS Code
1. Open folder `CyberShield-HK26-0020` in VS Code
2. Install Live Server extension
3. Right click `index.html` -> Open with Live Server
4. Done!
